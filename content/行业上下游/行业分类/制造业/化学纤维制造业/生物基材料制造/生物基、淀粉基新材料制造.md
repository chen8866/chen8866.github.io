| ‌**维度**‌     | ‌**合成纤维制造**‌                     | ‌**生物基材料制造**‌                   | ‌**纤维素纤维原料及纤维制造**‌           |
| ------------ | -------------------------------- | ------------------------------- | ---------------------------- |
| ‌**原料来源**‌   | 石油、天然气、煤等化石能源提取的小分子化合物（如乙烯、丙烯单体） | 玉米、甘蔗、蓖麻油等可再生生物质资源（非化石基碳源）      | 木材、竹子、棉短绒等天然纤维素材料            |
| ‌**生产工艺**‌   | 通过聚合反应生成高分子聚合物（如PET、PA），再经熔融纺丝成型 | 生物发酵提取单体（如乳酸）、化学聚合形成高分子链        | 溶解天然纤维素制成纺丝液，经湿法或干法纺丝再生为纤维   |
| ‌**典型产品**‌   | 涤纶（PET）、锦纶（PA）、氨纶（PU）、丙纶（PP）     | 聚乳酸（PLA）、生物基聚酯（PEF）、生物基尼龙（PA56） | 粘胶纤维、莱赛尔（Lyocell）、莫代尔（Modal） |


| ‌**对比维度**‌ | ‌**生物基新材料制造**‌                                 | ‌**生物基化学纤维制造**‌                      |
| ---------- | ---------------------------------------------- | ------------------------------------ |
| ‌**定义范畴**‌ | 广义概念，包含所有以生物质为原料的化学品、塑料、纤维等材料（如聚乳酸/PLA、生物基PTT） | 狭义概念，专指以生物质为原料制成的纤维材料（如PLA纤维、海藻纤维）   |
| ‌**原料类型**‌ | 来源广泛：植物、动物、微生物及衍生物（如玉米秸秆、甲壳素）                  | 特定生物质：需含可纺性成分（如纤维素、壳聚糖、生物基单体）        |
| ‌**核心工艺**‌ | 涵盖生物炼制、化学合成、改性复合（如淀粉与PLA共混改性）                  | 聚焦纺丝工艺：溶液纺丝、熔融纺丝（如PLA熔融纺丝温度170-230℃） |
| ‌**产品分类**‌ | 包含非纤维形态：生物基塑料（PLA薄膜）、生物基橡胶（PHA弹性体）             | 仅限纤维形态：再生纤维（竹纤维）、合成纤维（生物基涤纶）         |
| ‌**降解性能**‌ | 部分不可降解（如生物基PTT材料）                              | 多数可降解（如PLA纤维堆肥降解率≥90%）               |
