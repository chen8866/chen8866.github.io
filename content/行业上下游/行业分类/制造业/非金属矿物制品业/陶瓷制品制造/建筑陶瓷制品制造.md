| **类别**‌        | ‌**原料与工艺特性**‌                                   | ‌**核心功能与定义**‌               |
| -------------- | ----------------------------------------------- | --------------------------- |
| ‌**陈设艺术陶瓷制造**‌ | 高岭土为主，手工塑形（泥条盘筑、捏塑）结合釉上彩绘，烧成温度1100-1300℃        | 侧重艺术性与观赏性，包括雕塑、摆件等非实用装饰品    |
| ‌**建筑陶瓷制品制造**‌ | 粘土、石英、长石混合压制，干法成型为主，高温烧制（1200-1300℃），需耐磨、抗冻性能优化 | 用于建筑物内外墙、地面的功能性材料（瓷砖、外墙砖等）  |
| ‌**其他陶瓷制品制造**‌ | 多样性配方（含工业废料回收利用），注浆成型或机械压制，中温烧制（900-1100℃）      | 涵盖园艺陶瓷、工业配件等非主流分类产品         |
| ‌**日用陶瓷制品制造**‌ | 高白泥或骨质瓷配方，注浆/滚压成型，施透明釉，釉下彩装饰，烧成温度1250-1350℃     | 满足日常餐饮、储藏的实用器具（餐具、茶具等）      |
| ‌**特种陶瓷制品制造**‌ | 氧化铝/氮化硅等非硅酸盐材料，等静压成型或流延法，超高温烧结（1600-1800℃）      | 满足高强度、耐腐蚀等特殊性能需求（电子元件、航天部件） |
| ‌**卫生陶瓷制品制造**‌ | 粘土混合滑石粉增强韧性，高压注浆成型，施乳浊釉，1250℃以上烧成，需抗菌和自洁功能设计    | 卫生间洁具产品（马桶、面盆等）             |
| ‌**园艺陶瓷制造**‌   | 低成本红陶土为主，露天干燥结合中低温素烧（800-1000℃），表面多保留自然肌理       | 服务于园林绿化的花盆、景观雕塑等            |
