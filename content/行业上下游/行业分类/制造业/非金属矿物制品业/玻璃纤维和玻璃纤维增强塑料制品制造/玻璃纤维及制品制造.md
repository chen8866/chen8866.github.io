| ‌**制造环节**‌         | ‌**定义及核心特征**‌                         | ‌**典型产品**‌                     |
| ------------------ | ------------------------------------- | ------------------------------ |
| ‌**玻璃制造**‌         | 以石英砂、纯碱等为原料，经高温熔融成型生产基础玻璃材料           | 平板玻璃（浮法玻璃）、器皿玻璃（瓶罐）、光学玻璃基板     |
| ‌**玻璃制品制造**‌       | 对基础玻璃进行二次加工或功能性处理，制成终端应用产品            | 建筑玻璃（中空玻璃、钢化玻璃）、医用玻璃器皿、实验室仪器   |
| ‌**玻璃纤维制造**‌       | 将玻璃原料熔融后拉丝制成纤维材料，直径5-25微米，具有高强度、耐腐蚀特性 | 连续玻璃纤维（长纤）、短切玻璃纤维（定长纤）、玻璃纤维布/毡 |
| ‌**玻璃纤维增强塑料制品制造**‌ | 将玻璃纤维与树脂基体复合，通过模压/注塑等工艺生产高性能复合材料      | 汽车部件（保险杠）、风电叶片、电子设备外壳、体育器材     |

| ‌**分类名称**‌         | ‌**材料组成**‌      | ‌**典型产品**‌       | ‌**核心工艺**‌                                     |
| ------------------ | --------------- | ---------------- | ---------------------------------------------- |
| ‌**玻璃纤维及制品制造**‌    | 单一无机材料（二氧化硅为主）  | 玻璃纤维纱、玻璃纤维布、短切原丝 | 1. 原料熔融（1400-1600℃）  <br>2. 铂铑合金漏板拉丝（直径5-24μm） |
| ‌**玻璃纤维增强塑料制品制造**‌ | 复合材料（玻璃纤维+树脂基体） | 玻璃钢管道、汽车保险杠、风电叶片 | 1. 纤维铺层  <br>2. 树脂浸润（手糊/模压/缠绕）  <br>3. 固化成型    |
