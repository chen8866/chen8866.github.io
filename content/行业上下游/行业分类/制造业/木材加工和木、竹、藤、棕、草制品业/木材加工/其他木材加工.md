| ‌**类别**‌     | ‌**定义与工艺特征**‌                                    | ‌**典型产品**‌   |
| ------------ | ------------------------------------------------ | ------------ |
| ‌**单板加工**‌   | 通过旋切、刨切或锯切工艺，将原木加工成厚度≤6mm的薄木片，主要用于胶合板基材及装饰贴面     | 单板、装饰薄木      |
| ‌**木片加工**‌   | 利用削片机将木材（含采伐剩余物）切割成规则薄片，尺寸通常为15-30mm，适用于造纸及纤维板原料 | 工业木片、生物质颗粒   |
| ‌**锯材加工**‌   | 通过带锯、圆锯等设备将原木纵向切割成特定规格的方材或板材，保留木材天然纹理            | 锯材（如板材、方木）   |
| ‌**其他木材加工**‌ | 涵盖防腐处理、碳化改性、拼接集成等非标准化加工，提升木材功能性或利用率              | 防腐木材、碳化木、集成材 |
